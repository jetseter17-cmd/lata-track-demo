# LATA TRACK — демо-сборка (живая вёрстка)

Полноценная вёрстка 1:1 с Figma `kfRB9pkEoNLR5m53tlv09r` (страница «прототип», Brutal):
Главная (frame 2585-1336) + Тюбинг (frame 2588-1749) + прелоадер (2598-1981).

## Запуск
```bash
cd site && python3 -m http.server 8090
# открыть http://localhost:8090/index.html
```
- `index.html` — главная. Прямой заход: прелоадер (лого → фото → полосы+проценты, нижняя полоса быстрее → FLIP фото в hero → каскад текста).
- `tubing.html` — Тюбинг. Переходы между страницами — шторкой (клик по «ТЮБИНГ» в меню или карточке 02).
- `?static` — без анимаций, сразу финальный кадр (для пиксельной сверки).

## Структура
- `css/main.css` — токены, вёрстка обеих страниц (абсолют по координатам макета, канва 1440, клип как у фрейма), хореография анимаций.
- `js/app.js` — прелоадер (проценты/полосы/FLIP через WAAPI), шторка-переход, реавилы по скроллу, автозум канвы под окно.
- `assets/img/` — ассеты, выгруженные из Figma MCP (+ `hero-src.png` — оригинал фото лыжника 2136×1048 из `img/`).
- `assets/fonts/` — self-hosted Onest / Rubik / Space Mono (+ PT Mono как кириллический фоллбэк для моно).

## Анимации (по emil-design-eng / animations.dev)
- Кривые: `--ease-out: cubic-bezier(.23,1,.32,1)`, `--ease-in-out: cubic-bezier(.77,0,.175,1)`, FLIP `cubic-bezier(.72,0,.16,1)`.
- UI-реакции ≤300 мс, длинная хореография только у прелоадера/переходов; `scale(0.97)` на нажатии кнопок; реавилы one-shot через IntersectionObserver; уважается `prefers-reduced-motion`.
